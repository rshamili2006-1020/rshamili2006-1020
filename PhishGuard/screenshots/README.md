# Screenshots

Place the following screenshot files in this folder after running the application:

| File             | What to Capture                              |
| ---------------- | -------------------------------------------- |
| `login.png`      | The login page at `http://127.0.0.1:5000`    |
| `register.png`   | The registration page                        |
| `dashboard.png`  | The reports dashboard with at least 2-3 rows |
| `add_report.png` | The "Report a Phishing URL" form             |
| `mysql.png`      | The `phishguard` database tables in phpMyAdmin |

**How to capture:** Run `python app.py`, open each page in your browser, and
take a screenshot (Win+Shift+S on Windows, Cmd+Shift+4 on macOS).

These screenshots are tracked in Git — the `.gitignore` is configured to keep
`*.png` files in this folder.
